# DevOps

Moim zdaniem DevOps to połączenie dwóch światów:
Developera i Admina. Jego celem jest automatyzacja procesów,
tworzenie efektywnych środowisk pracy oraz szybkie i bezbłędne 
dostarczanie zmian/updatów. DevOps korzystając z narzędzi do 
monitoringu, testowania, i wdrażania aplikacji sprawia że zespoły
mogą pracować efektywniej i popełniać mniej błędów.

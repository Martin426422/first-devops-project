# Development Tools

## WSL
Windows Subsystem for Linux umożliwia uruchamianie środowiska 
Linux bezpośrednio w systemie Windows bez potrzeby korzystania z 
maszyny wirtualnej.

## Ubuntu
Dystrybucja Linux używana jako środowisko pracy do nauki i 
wykonywania zadań DevOps.

## Git
System kontroli wersji służący do śledzenia zmian w kodzie, 
zarządzania historią projektu oraz współpracy z innymi 
programistami.

## Docker
Platforma umożliwiająca uruchamianie aplikacji w izolowanych 
kontenerach, co ułatwia wdrażanie i przenoszenie środowisk.

## curl
Narzędzie wiersza poleceń służące do pobierania danych z 
internetu oraz komunikacji z API.

## wget
Program umożliwiający pobieranie plików z sieci przy użyciu 
terminala.

## unzip
Narzędzie służące do rozpakowywania archiwów ZIP.

## htop
Interaktywny monitor procesów pozwalający obserwować 
wykorzystanie procesora, pamięci i uruchomione procesy.

## tree
Program wyświetlający strukturę katalogów w postaci czytelnego 
drzewa.

## jq
Narzędzie do przetwarzania, filtrowania i formatowania danych 
zapisanych w formacie JSON.

## Zsh
Rozszerzona powłoka systemowa oferująca większe możliwości 
konfiguracji i wygodniejszą pracę niż standardowy Bash.

## Oh My Zsh
Framework rozszerzający funkcjonalność powłoki Zsh poprzez 
motywy, aliasy i wtyczki.

## zsh-autosuggestions
Wtyczka do Zsh podpowiadająca komendy na podstawie historii 
wcześniej używanych poleceń.
